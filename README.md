# RideHub - Bike & Scooter Showroom

RideHub is a full-stack bike and scooter showroom website designed to showcase vehicles, display specifications and offers, and manage customer enquiries through an admin panel.

## Live Demo

- **Customer Website:** https://ridehubshowroom.netlify.app/
- **Admin Panel:** https://ridehubshowroom.netlify.app/admin/html/login.html

*The admin panel requires administrator credentials.*

## Features

### Customer Website
- Browse motorcycles and scooters.
- View vehicle details, specifications, and pricing.
- Explore available offers.
- Discover showroom services and information.
- Submit vehicle enquiries and contact messages.

### Admin Panel
- Administrator login and authentication.
- Dashboard with showroom statistics.
- Manage vehicle information.
- Manage offers and their status.
- View and manage customer enquiries.
- View and manage contact messages.

## Technologies Used

**Frontend**
- HTML5
- CSS3
- JavaScript

**Backend**
- Node.js
- Express.js
- REST APIs

**Database**
- MySQL
- Aiven

**Deployment**
- Netlify — Frontend hosting
- Render — Backend hosting

## Project Purpose

RideHub was developed as a practical full-stack project to explore frontend development, REST API integration, database connectivity, administrator authentication, and web application deployment.
